# .genAiDoc — Design & Development Guidelines

This folder contains UI/UX patterns, component guidance, accessibility checklists, and development style rules for the "Read Aloud Akie" site. Use these files as the canonical reference when making design, accessibility, and code changes.

Files:
- `UI-UX-patterns.md` — visual and interaction patterns to follow.
- `development-style.md` — coding conventions, tooling and branch rules.
- `components.md` — component-level guidance and examples (hero, cover, tile, story page).
- `accessibility.md` — a short checklist to validate accessibility.
- `git-and-deploy.md` — GitHub Pages and DNS deployment notes.
- `seo.md` — how the site is found in search, and what each new book needs.
- `new-book-checklist.md` — every step for putting a new book on the shelf (including its published date).

Keep these documents short, focused, and up to date. When you change a pattern or introduce a new component, update the relevant file and add a short note referencing the PR.
